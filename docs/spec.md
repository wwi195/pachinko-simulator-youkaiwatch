# eフィーバー妖怪ウォッチ シミュレーター 仕様

作成日：2026-11-21。スペックと演出は、Discordでユーザーと確認して決めた。
ベースは `pachinko-simulator-sao` を使い、設定のプルダウンは `pachinko-simulator-ghoul` の形にした。

## 出典
- 必勝本 https://p.hisshobon.jp/machine/4794/1/2 、 https://hisshobon.com/web/185334/
- 一撃 https://1geki.jp/pachinko/e_youkai_watch/
- SANKYO公式のスペック表は本文を取得できなかった。

## 遊技条件
- 等価（4円/玉）固定。軍資金の上限はなし。
- 回転数/千円は 13／15／17（ボーダー・初期値）／19／20 から選ぶ。
- 実際の獲得球は 表示 − 表示/15（1500→1400、300→280、3000→2800）。

## 通常時
- 大当たり 1/319.7。外れは何も起きず、回転数だけ進む。
- 入賞時フラッシュ：当たりは必ずフラッシュから来る。信頼度は 25%／40%（初期値）／EX から選ぶ。
  - EX：フラッシュ＝当たり確定。RUSHかどうかもその場で見せ、RUSHでなければ「通常当たり」でガシャなしにコマチャレンジへ。
- ヘソ振り分け：3000個（レジェンドヨーデルエクストラ・RUSH直行）0.5%、妖怪FEVER 300個 99.5%。
- 妖怪FEVER →「妖怪ガシャチャレンジへ」→ ジャッジ。成功率 49.5/99.5 ≒ 49.7%。
  - 15%でレバー（「引け」・成功92%）、85%でボタン（「押せ」・成功 約42.3%。合計が49.7%になるよう逆算）。
  - 成功 → RUSH、失敗 → コマチャレンジ。

## RUSH「ヨーデルSONIC怪闘」（転落タイプ）
1回転ごとに次を同時に抽選する（同じ回で両方は起きない）。
- 直撃当たり 1/47.6 → 無条件で当たり、RUSH継続。
- 最終決戦 1/88.0 → 1回だけの勝負。1/4で勝利（1500個＋継続、振り分けなし）、3/4で敗北＝転落。
- 合算：図柄揃い 1/41.9、転落 1/117.3、RUSH継続率 約74%。

直撃当たりの振り分けは、公表の振り分け（最終決戦の勝利込み）から勝利分（全体の約11.9%、全部1500個）を抜いて割り直した。

| 種類 | 割合 | 出玉 |
|---|---|---|
| SONIC FEVER | 42.45% | 1500個 |
| ピン刺しチャンス失敗 | 25.31% | 1500個 |
| ピン刺しチャンス成功 | 21.80% | 3000個（レジェンドヨーデルエクストラ） |
| エンマインパクト | 3.97% | 3000個 |
| ウバウネ決戦 | 6.47% | 3000個から、50%で勝つたびに1500個上乗せ（上限なし） |

## コマチャレンジ
- 時短100回、大当たり 1/399.6（引き戻し率 約22.1%）。
- RUSHに入らなかったとき、RUSHが終わったとき（最終決戦の敗北）に必ず入る。
- 引き戻したら1500個＋RUSH。外したら通常時へ。

## 全体の数字（テストで確認）
- 実質RUSH突入率 約61%、トータル継続率 約80%。

## 画面
- 色は赤・黄・白。
- RUSH・コマチャレンジ中は 1回転／10回転／スキップ。外れても「外れ」画面は出さない。
  - RUSHのスキップは当たりか最終決戦まで、コマチャレンジのスキップは当たりか残り10回まで。
- 連チャン数は初当たりを1連目として数える。RUSHに入ったセッションは、終わるとリザルトとランキングを出す。
